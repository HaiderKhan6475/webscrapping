## 💾 Data Storage & Databases Used
Extracting data is only half the battle! To handle data professionally, I have exported and structured the scraped data into various formats and database management systems:

* 📄 **Flat Files:** Exported clean data into `.csv` and `.json` formats for quick analysis.
* 🍃 **MongoDB:** Structured NoSQL database storage for handling raw, dynamic, or unstructured scraped data.
* 🗄️ **PostgreSQL / SQL:** Relational database storage using structured tables and optimized queries for complex datasets.
